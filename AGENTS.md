# AGENTS.md — Octopus

## Repository

`github.com/bestruirui/octopus` — LLM API aggregation & load balancing service.

## Quick start

```bash
# backend
go run main.go start

# frontend dev (separate terminal, Vite proxies /api -> :8080)
cd web && pnpm install && pnpm dev

# production build (must happen before backend start)
cd web && pnpm install && pnpm build  # outputs to ../static/out/
go run main.go start
```

## Build

`scripts/build.sh release` — builds frontend, runs price sync, cross-compiles for all platforms, creates Docker binaries and archives.

## Key structure

| Path | Role |
|------|------|
| `cmd/` | CLI entrypoints (cobra): `start`, `version` |
| `internal/server/` | Gin HTTP server, routes, handlers, middleware |
| `internal/relay/` | Request relay/load-balancing core (uses axonhub/llm) |
| `internal/conf/` | Config loading (viper, JSON, `OCTOPUS_` env vars) |
| `internal/db/` | GORM DB init (SQLite / MySQL / PostgreSQL) |
| `internal/op/` | Business logic layer (cache, CRUD, stats) |
| `internal/price/` | Model pricing. `presets.go` is **auto-generated** |
| `internal/task/` | Background tasks (model sync, channel sync, etc.) |
| `web/` | React + TypeScript + Vite frontend |
| `static/static.go` | embeds `static/out/` into Go binary |

## Dependencies

- `go.mod` has `replace` directives for `github.com/gin-contrib/sse` and `github.com/tmaxmax/go-sse` pointing to `github.com/looplj/` forks.
- Frontend requires `pnpm`.

## Generated code

`internal/price/presets.go` is generated by `scripts/updatePrice.py` (fetches from `models.dev/api.json`). **Do not edit manually** — run `python3 scripts/updatePrice.py` to regenerate.

## Config

- Default path: `data/config.json` (auto-created on first run)
- Override: `--config` flag or `OCTOPUS_` env vars (e.g. `OCTOPUS_SERVER_PORT`, `OCTOPUS_DATABASE_TYPE`, `OCTOPUS_SERVER_JWT_SECRET`)
- `server.jwt_secret` is auto-generated and written to config on first start if empty
- Default admin: `admin` / `admin` (must change password on first login)

## Tests

No test files exist in this repository.

## CI

- Push to `master` triggers full release build (binaries + Docker images) via `release.yaml`
- Push tag `v*` triggers changelog generation and merges `dev` into `master`

## Misc

- Shutdown gracefully with `Ctrl+C` / `SIGTERM` (not `kill -9`) to flush in-memory stats to DB
- Docker entrypoint supports `PUID`/`PGID` env vars for non-root runtime
